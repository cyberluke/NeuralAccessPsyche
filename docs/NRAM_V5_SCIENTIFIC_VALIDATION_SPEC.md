## Complete governing specification

NRAM v5 is an existing single-user Streamlit research application running locally with SGLang on Windows 11, Docker Desktop, WSL2, Ubuntu, and one RTX 4090. Do not optimize for multi-user production deployment, horizontal scaling, high concurrency, or maximum throughput. Use concurrency 1 and disable overlap scheduling whenever required for deterministic stateful inference. The objective is scientific correctness and reproducible evidence for an arXiv paper.

Audit, repair, complete, and experimentally verify the entire NRAM v5 inference-control stack. Code/file presence, passing mocks, changed prose, different random outputs, or telemetry emitted by unused code are not evidence. Every claimed feature must be connected to the live SGLang inference path, execute during real GPU generation, be observable via runtime telemetry, be isolated in a controlled ablation, cause the intended measurable effect, and be reproducible from recorded commands/configuration. Do not describe NRAM v5 as complete, release-ready, or paper-ready until all criteria are satisfied.

Preserve valid behavior and tests from baseline commit 6b92283 (`feat: add verified SGLang engine baseline`). Treat claims of 269/273 passing tests, phrase trie blocking, forced-token sampling, concept bias, entropy control, hallucination guards, concept capsules, multi-vector steering, activation addition, conceptor steering, hidden-state probes, DExperts, branch-and-tournament generation, shared processor package, telemetry, and single-request operation as unverified until demonstrated through real runtime. Identify every one of the four failures, determine cause, and resolve it; do not call failures unrelated without concrete written evidence.

Scientific rules: use the real model, tokenizer, SGLang server, and GPU runtime for acceptance proofs; mocks are permitted only for units, never acceptance. No silent prompt-only fallback. Do not replace dill with cloudpickle unless the installed SGLang contract demonstrably requires it. Static vocabulary bias is not DExperts. Random output variation is not ablation. Importability is not live wiring. A logits-only processor cannot prove hidden-state intervention. Closed-loop means a measured runtime signal changes a subsequent intervention. Branch-and-tournament means multiple candidates are generated, scored, and selected. Unsupported requested features fail loudly. Inspect exact installed SGLang version/source/API before integration changes. Prefer official extension mechanisms; use only a minimal version-pinned patch when official hooks cannot correctly provide the intervention.

Phase 5 logits: entropy servo measures actual next-token distribution, logs per-step entropy before/target/error/PID terms/applied scale or temperature/entropy after/clamps, tests low/medium/high targets with same prompt/seeds, moves stably toward target without NaN, differs from fixed temperature, and resets request state. Phase 6 DExperts: must obtain distinct same-position next-token distributions from base, expert, anti-expert, and apply documented equation such as z_final = z_base + alpha*z_expert - beta*z_anti (or explicitly selected exact variant). Sequential expert evaluation is acceptable on one RTX 4090. Prove execution/checkpoints/adapters, tokenizer/vocab compatibility or alignment, decode-position alignment, tensor equation, zero coefficients reproduce base, alpha moves toward expert, beta suppresses anti-expert. Record latency/VRAM as metadata only.

Phase 7 representation control: a logits-only processor cannot implement ActAdd, conceptors, probes, ReFT, head gating, or latent closed loop. Multi-layer/multi-vector tests near 25/50/70/85 percent model depth mapped to real indices; treat depth effects as hypotheses. Conceptors perform real subspace/projection with dimension/device/dtype/construction/aperture/projection/positive-negative/composition/zero/downstream controls; weighted vector addition is not a conceptor. Probes require separate train/validation/test, task/labels/dataset/balance/splits/leakage/AUROC/precision/recall/F1/calibration/baseline. Closed-loop causal chain must align token positions: hidden state -> probe score -> decision -> changed strength -> changed subsequent hidden state/logits. Post-generation display is observability only.
