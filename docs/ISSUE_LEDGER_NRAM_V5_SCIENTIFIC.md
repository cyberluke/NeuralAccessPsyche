## Status vocabulary

- `CONFIRMED`: independently reproduced defect, not yet repaired.
- `FIXED_UNVERIFIED`: Builder remediation and regression evidence exist; independent verification is still required.
- `BLOCKED`: required scientific mechanism or historical artifact is unavailable and is not simulated.
- `UNCONFIRMED`: evidence is insufficient to attribute a cause.
- `ACCEPTED_RISK`: bounded limitation retained explicitly for the documented local research scope.

`VERIFIED_FIXED` is intentionally unavailable as a Builder conclusion. Rows using it below only preserve the independent result from `runtime-reverify-isolated-ad274a2-20260728T010200Z`; this remediation does not re-verify them.
